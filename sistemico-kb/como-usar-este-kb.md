# Cómo Usar Este KB

Esta guía explica la estructura, navegación y convenciones de la Knowledge Base de Pensamiento Sistémico.

## Navegación por Módulos

La KB está organizada en 9 módulos numerados. Cada módulo tiene un `README.md` como punto de entrada:

| Módulo | Descripción |
|--------|-------------|
| **01-Fundamentos** | Conceptos básicos y paradigma sistémico |
| **02-Conceptos-Clave** | El vocabulario universal del pensamiento sistémico |
| **03-Grandes-Pensadores** | Biografías y contribuciones de los autores clave |
| **04-System-Dynamics** | Modelado y simulación de sistemas |
| **05-Aplicaciones-Clasicas** | Casos de aplicación en organizaciones y políticas |
| **06-Sistemas-Complejos** | CAS, teoría del caos, redes complejas |
| **07-Pensamiento-Sistemico-y-IA** | Síntesis moderna con inteligencia artificial |
| **08-Herramientas-y-Practicas** | Técnicas aplicables en el día a día |
| **09-Ruta-Aprendizaje** | Itinerarios de estudio según perfil |

## Convenciones

### Frontmatter

Toda nota incluye:

```yaml
---
tags:
  - sistemico
  - sistemico/<modulo>
  - type/<tipo>
source: <referencia>
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

### Tipos de nota

| Type | Descripción |
|------|-------------|
| `type/concepto` | Idea o principio fundamental |
| `type/biografia` | Perfil de un pensador |
| `type/guia` | Instructivo o tutorial |
| `type/herramienta` | Técnica o método práctico |
| `type/indice` | Página de navegación |

### Wikilinks

Usamos `[[wikilinks]]` para conectar notas. Si una nota no existe, el enlace sirve como placeholder para contenido futuro.

### Sección "Conexión con IA"

Las notas sobre conceptos clásicos incluyen una sección al final que vincula el concepto con aplicaciones modernas de IA, para tender un puente entre la teoría clásica y la práctica contemporánea.

4. Si quieres profundizar: [[09-Ruta-Aprendizaje/03-itinerario-avanzado\|Ruta Avanzada]]
