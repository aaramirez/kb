# 01 — Fundamentos del Pensamiento Sistémico

El pensamiento sistémico es una disciplina para ver la totalidad: un marco conceptual que nos permite identificar las interconexiones, los patrones de cambio y las estructuras subyacentes que dan forma al comportamiento de los sistemas.
