# Paradigma Mecanicista vs. Sistémico

## Dos Cosmovisiones

| Dimensión | Mecanicista (Descartes/Newton) | Sistémico |
|-----------|-------------------------------|-----------|
| **Mundo** | Máquina predecible | Red viva, dinámica e impredecible |
| **Conocimiento** | Reduccionismo: entender las partes | Holismo: entender las relaciones |
| **Causalidad** | Lineal (A → B → C) | Circular (A ↔ B ↔ C) |
| **Relación** | Parte separada del todo | Parte definida por el todo |
| **Cambio** | Externo, forzado | Interno, emergente |
| **Medición** | Cantidad, precisión | Patrón, cualidad, contexto |
| **Error** | Falla del componente | Propiedad del sistema |

## El Problema del Reduccionismo

El pensamiento mecanicista nos ha dado avances extraordinarios. Pero falla cuando:

- Las interacciones son **no lineales** (pequeña causa, gran efecto)
- Hay **retardos** entre acción y consecuencia
- El sistema tiene **bucles de retroalimentación** que cancelan o amplifican efectos
- Las partes son **interdependientes** (no se pueden aislar)

> "El error de nuestra época es pensar que los problemas se pueden resolver moviendo las piezas del tablero, sin entender que el tablero mismo es parte del problema." — Adaptado de Ackoff

## Ejemplo: Salud

- **Mecanicista**: El cuerpo es una máquina. Enfermedad = pieza dañada. Se repara o reemplaza (cirugía, fármaco).
- **Sistémico**: La salud emerge de la interacción entre genética, entorno, alimentación, estrés, microbiota, relaciones sociales. La enfermedad es un desequilibrio del sistema.

## Conexión con IA

El debate **simbólico vs. conexionista** en IA refleja esta tensión:
- **Mecanicista**: Sistemas expertos basados en reglas (partes → todo)
- **Sistémico**: Redes neuronales donde el comportamiento emerge de conexiones (relaciones → todo)

Los [[07-Pensamiento-Sistemico-y-IA/02-sistemas-multi-agente|sistemas multi-agente]] son inherentemente sistémicos: el comportamiento global emerge de interacciones locales entre agentes autónomos.
