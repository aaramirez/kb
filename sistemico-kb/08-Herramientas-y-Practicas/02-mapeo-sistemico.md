# Mapeo Sistémico

El mapeo sistémico es un conjunto de técnicas visuales para representar sistemas complejos. No buscan precisión matemática, sino **comprensión compartida**.

## Técnicas

### 1. Rich Pictures (Imágenes Ricas)

Dibujos que capturan la esencia de un sistema complejo, incluyendo elementos, relaciones, conflictos y emociones.

**Cuándo usarlo**: Fase inicial de diagnóstico. Útil para alinear perspectivas.

**Elementos**:
- Iconos y dibujos simples
- Flechas de relación
- Anotaciones emocionales (estrés, conflicto, alegría)
- Límites borrosos (no hay estructura fija)

### 2. Mapas de Influencia

Muestran qué variables influyen sobre cuáles, sin los detalles de signo y bucle de un CLD formal.

**Ejemplo**:
```
  Calidad de código ──→ Satisfacción del equipo
       ↑                       │
       │                       ▼
  Presión de fechas ←── Productividad
```

### 3. Mapas de Actores (Stakeholder Mapping Sistémico)

Identifica a los actores y sus relaciones, incluyendo influencias no obvias. Ver [[08-Herramientas-y-Practicas/04-analisis-stakeholders-sistemico]].

## Guía Práctica

1. **Define el foco**: ¿Qué problema o sistema quieres mapear?
2. **Identifica elementos**: Variables, actores, recursos
3. **Dibuja relaciones**: Conexiones, influencias, conflictos
4. **Busca bucles**: ¿Dónde hay causalidad circular?
5. **Comparte**: El mapa es una herramienta de diálogo, no un producto final
