# El Iceberg Sistémico

El iceberg sistémico es la herramienta más conocida del pensamiento sistémico. Nos ayuda a pasar de **reaccionar a eventos** a **rediseñar estructuras** y **transformar modelos mentales**.

## Los 4 Niveles

```
        ╱╲         ╱╲
       ╱  ╲       ╱  ╲      Nivel 1: EVENTOS
      ╱    ╲     ╱    ╲     ¿Qué está pasando?
     ╱      ╲   ╱      ╲    (Reaccionamos)
    ╱        ╲ ╱        ╲
   ╱────────────────────────╲
  ╱                          ╲   Nivel 2: PATRONES
  ╱                          ╲  ¿Qué tendencia hay?
  ╱                          ╲  (Anticipamos)
 ╱─────────────────────────────╲
╱                               ╲ Nivel 3: ESTRUCTURAS
╱                               ╲ ¿Qué reglas lo causan?
╱                               ╲ (Diseñamos)
╱─────────────────────────────────╲
╱  MODELOS MENTALES                ╲ Nivel 4: MODELOS MENTALES
╱  (creencias, supuestos,           ╲ ¿Qué creencias lo sostienen?
╱   paradigmas)                      ╲ (Transformamos)
╱──────────────────────────────────────╲
```

## Cómo Usarlo

### Nivel 1: Eventos
**Pregunta**: ¿Qué pasó?
**Trampa**: Quedarse aquí lleva a apagar incendios.

### Nivel 2: Patrones
**Pregunta**: ¿Qué tendencia observamos a lo largo del tiempo?
**Valor**: Permite anticipar, no solo reaccionar.

### Nivel 3: Estructuras
**Pregunta**: ¿Qué reglas, políticas, incentivos o flujos de información generan estos patrones?
**Valor**: Permite rediseñar el sistema.

### Nivel 4: Modelos Mentales
**Pregunta**: ¿Qué creencias y supuestos profundos crean estas estructuras?
**Valor**: Permite transformar la fuente del sistema.

## Ejemplo Aplicado

| Nivel | Pregunta | Ejemplo: Baja calidad de código |
|-------|----------|--------------------------------|
| Evento | ¿Qué pasó? | Bug en producción |
| Patrón | ¿Qué tendencia? | Cada sprint hay más bugs |
| Estructura | ¿Qué lo causa? | No hay code review, presión de fechas, deuda técnica |
| Modelo mental | ¿Qué creencias? | "Entregar rápido es más importante que calidad" |

## Aplicación en IA

| Nivel | Pregunta | Ejemplo: Alucinaciones |
|-------|----------|----------------------|
| Evento | ¿Qué pasó? | El modelo respondió con información falsa |
| Patrón | ¿Qué tendencia? | Las alucinaciones aumentan con contextos largos |
| Estructura | ¿Qué lo causa? | Arquitectura autoregresiva, falta de verificación |
| Modelo mental | ¿Qué creencia? | "Los LLMs deben poder responder todo sin herramientas externas" |
