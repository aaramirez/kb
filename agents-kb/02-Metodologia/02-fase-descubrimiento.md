# Fase 1: Descubrimiento

## Objetivo

Identificar las mejores oportunidades para implementar agentes de IA en la organización.

## Duración: 2-4 semanas

## Actividades

### 1. Mapeo de Procesos (Semana 1)

Enumerar todos los procesos del área y clasificarlos:

| Proceso | Volumen | Variabilidad | ¿Agente? | Prioridad |
|---------|---------|--------------|----------|-----------|
| Soporte nivel 1 | Alto | Alto | Sí | 🔴 Alta |
| Generación de reportes | Medio | Bajo | Parcial | 🟡 Media |
| Onboarding clientes | Medio | Alto | Sí | 🔴 Alta |
| Auditoría compliance | Bajo | Medio | No | ⚪ N/A |

### 2. Evaluación de Oportunidades (Semana 2)

Para cada proceso candidato, evaluar:

**Factor 1: Impacto (1-5)**
- ¿Cuánto tiempo se ahorra?
- ¿Cuántos errores se reducen?
- ¿Mejora la experiencia del cliente?

**Factor 2: Viabilidad (1-5)**
- ¿Los datos están disponibles?
- ¿Es técnicamente factible?
- ¿Hay resistencia al cambio?

**Factor 3: Riesgo (1-5, donde 1 = bajo riesgo)**
- ¿Es crítico para el negocio?
- ¿Hay implicaciones regulatorias?
- ¿Requiere acceso a sistemas sensibles?

**Score = Impacto × Viabilidad / Riesgo**

### 3. Selección del Piloto (Semana 3)

Elegir el proceso con **mayor Score** que:
- Sea visible para la dirección
- Tenga datos disponibles
- Se pueda completar en 4-6 semanas
- Tenga unROI claro y medible

### 4. Diseño del Piloto (Semana 4)

Definir:
- **Objetivo**: Qué logra el agente
- **Métricas**: Cómo se mide el éxito
- **Alcance**: Qué hace y qué no hace
- **Temporal**: Cuándo empieza y termina
- **Equipo**: Quién participa
