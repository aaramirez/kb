# Agentes del Ciclo de Vida del Cliente

## El Ciclo Completo

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ PROSPECT│──▶│  VENTA  │──▶│ONBOARDING│──▶│ SERVICIO│──▶│ RETENCIÓN│
│         │   │         │   │         │   │         │   │         │
│ Lead    │   │ Cierre  │   │ Alta    │   │ Soporte │   │ Renewal │
│ scoring │   │ propuesta│  │ cliente │   │ y upsell│   │ y win-  │
│         │   │         │   │         │   │         │   │ back    │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
```

## Agentes por Fase

### Prospección
| Agente | Función | Impacto |
|--------|---------|---------|
| Lead Scoring | Prioriza prospectos | +35% conversión |
| Competitive Intel | Analiza competencia | Mejores propuestas |

### Venta
| Agente | Función | Impacto |
|--------|---------|---------|
| Propuesta Automática | Genera propuestas | -80% tiempo |
| Pricing Intel | Optimiza precios | +20% margen |

| Agente | Función | Impacto |
|--------|---------|---------|
| Welcome Agent | Guía alta inicial | -60% tiempo |

| Agente | Función | Impacto |
|--------|---------|---------|
| Soporte N1 | Resuelve consultas | -70% carga |
| Upsell Agent | Identifica oportunidades | +15% ARPU |

### Retención
| Agente | Función | Impacto |
|--------|---------|---------|
| Churn Predictor | Detecta riesgo | +30% retención |
| Win-back | Recupera clientes | +20% recuperación |
