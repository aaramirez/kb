# Ruta: Ingeniero de Software

## Objetivo

Usar agentes de IA para aumentar productividad en desarrollo: code review, testing, documentación.

## Itinerario

### Paso 1: Harness Personal (30 min)
- [[03-Harness-Por-Rol/04-harness-ingenieria-software|Harness Desarrollador]]
- [[03-Harness-Por-Rol/01-diseno-de-harnesses|Diseño de Harnesses]]

### Paso 2: Agentes para Dev (1 hora)
- Code review agent
- Testing agent
- Documentation agent

### Paso 3: Integración (1 hora)
- Integrar con GitHub
- Integrar con CI/CD
- Integrar con documentación

### Paso 4: Optimización (30 min)
- Medir productividad
- Ajustar prompts
- Compartir mejores prácticas

## Métricas Personales

| Métrica | Target |
|---------|--------|
| Tiempo de code review | -50% |
| Cobertura de tests | +30% |
| Documentación generada | +80% |
