## ¿Qué es un Harness?

Un **harness** es la configuración completa del entorno de un agente:
- **Modelo**: Qué LLM usa
- **Permisos**: Qué puede hacer
- **Herramientas**: A qué sistemas accede
- **Contexto**: Qué información tiene disponible
- **Reglas**: Cómo se comporta

Ver [[01-diseno-de-harnesses|Diseño de Harnesses]] para la metodología completa.
