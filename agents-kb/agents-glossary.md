# Glosario de Agentes Empresariales

## A

**Agente de IA**: Sistema autónomo que percibe su entorno, toma decisiones y ejecuta acciones para lograr un objetivo específico, utilizando modelos de lenguaje como cerebro de razonamiento.

**Agente de Atención al Cliente**: Agente especializado en interactuar con clientes para resolver consultas, gestionar servicios y escalalar problemas complejos.

**Agente de Comunicaciones**: Agente que gestiona flujos de información entre sistemas, equipos o departamentos de forma automatizada.

**Agente de Datos**: Agente que procesa, transforma y analiza información de múltiples fuentes para generar insights accionables.

**Agente de Monitoreo**: Agente que supervisa sistemas, redes o procesos en tiempo real, generando alertas cuando detecta anomalías.

**Agente de Procesos**: Agente que ejecuta tareas repetitivas siguiendo reglas de negocio definidas, liberando tiempo humano para trabajo de mayor valor.

**Agente Orquestador**: Agente que coordina la ejecución de múltiples sub-agentes para completar tareas complejas que un solo agente no podría resolver.

## C

**Cadena de Agentes (Agent Chain)**: Patrón arquitectónico donde la salida de un agente se convierte en la entrada del siguiente, creando un pipeline de procesamiento.

**Contexto de Agente**: Información que el agente tiene disponible para tomar decisiones, incluyendo historial, reglas, permisos y acceso a herramientas.

## D

**Deducción**: Capacidad del agente de razonar desde reglas generales hacia conclusiones específicas, usando lógica formal o inferencia estadística.

## E

**Empoderamiento con Agentes**: Proceso de delegar decisiones y acciones a agentes de IA, permitiendo que los equipos se enfoquen en trabajo estratégico.

**Escalamiento (Escalation)**: Proceso de transferir un caso de un agente a otro (humano o más capaz) cuando el agente actual no puede resolverlo.

## F

**Framework de Adopción**: Metodología estructurada para implementar agentes de IA en una organización, desde el descubrimiento hasta la escala.

## H

**Harness**: Configuración completa del entorno de trabajo de un agente: modelo, permisos, herramientas, contexto y reglas de comportamiento.

**Harness por Rol**: Diseño de harnesses personalizados para cada cargo de la organización, considerando sus necesidades específicas y nivel de acceso.

## I

**Inducción**: Capacidad del agente de generalizar desde ejemplos específicos hacia reglas o patrones más amplios.

**Integración**: Conexión del agente con sistemas externos (APIs, bases de datos, CRM, ERP) para ejecutar acciones en sistemas reales.

## L

**Loop de Agentes**: Patrón donde un agente ejecuta una acción, evalúa el resultado, y decide si continuar, ajustar o detenerse.

## M

**Modelo de Lenguaje (LLM)**: Red neuronal entrenada para generar y comprensión de texto, que sirve como "cerebro" de razonamiento del agente.

## O

**Orquestación**: Coordinación de múltiples agentes para trabajar de forma colaborativa en la resolución de tareas complejas.

## P

**Permisos de Agente**: Restricciones que definen qué puede y qué no puede hacer un agente (leer, editar, ejecutar comandos, acceder a sistemas).

**Prompt**: Instrucción o conjunto de instrucciones que define el comportamiento, personalidad y objetivos de un agente.

## R

**Retrieval-Augmented Generation (RAG)**: Técnica que combina recuperación de información de bases de conocimiento con generación de texto del LLM.

**Role-Based Harness**: Harness diseñado específicamente para un cargo o función de la organización.

## S

**Skill**: Conjunto de instrucciones y herramientas especializadas que un agente puede cargar bajo demanda para realizar tareas específicas.

**Sub-agente**: Agente secundario invocado por un agente principal para manejar tareas especializadas dentro de un flujo de trabajo.

**Sistema de Agentes**: Conjunto coordinado de agentes que trabajan juntos para lograr objetivos organizacionales.

## T

**Telco**: Empresa de telecomunicaciones. Contexto principal de este KB.

**Tool (Herramienta)**: Capacidad que un agente tiene para interactuar con el mundo exterior: leer archivos, ejecutar comandos, hacer búsquedas, enviar emails, etc.

## V

**Vector Store**: Base de datos especializada en almacenar y buscar representaciones vectoriales de texto, usada para RAG.
