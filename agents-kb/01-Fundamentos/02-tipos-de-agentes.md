# Tipos de Agentes

## Clasificación por Autonomía

### Nivel 1 — Asistente (Copilot)
- **Autonomía**: Baja
- **Rol**: Sugiere, no ejecuta
- **Ejemplo**: Asistente de código, asistente de escritura
- **Uso telco**: Ayuda a escribir documentación técnica

### Nivel 2 — Agente Ejecutor
- **Autonomía**: Media
- **Rol**: Ejecuta tareas predefinidas
- **Ejemplo**: Agente de facturación, agente de reporting
- **Uso telco**: Genera reportes de consumo自动amente

### Nivel 3 — Agente Autónomo
- **Autonomía**: Alta
- **Rol**: Toma decisiones dentro de límites
- **Ejemplo**: Agente de monitoreo de red, agente de soporte
- **Uso telco**: Detecta anomalías y ejecuta acciones correctivas

### Nivel 4 — Agente Orquestador
- **Autonomía**: Muy alta
- **Rol**: Coordina otros agentes
- **Ejemplo**: Agente de proceso completo
- **Uso telco**: Gestiona ciclo completo de un ticket de soporte

## Clasificación por Área

| Área | Tipo de Agente | Ejemplo |
|------|---------------|---------|
| **Atención al Cliente** | Agente conversacional | Chat de soporte con IA |
| **Soporte Técnico** | Agente de diagnóstico | Diagnóstico自动o de fallas |
| **Redes** | Agente de monitoreo | Alertas predictivas de red |
| **Ventas** | Agente de recomendación | Ofertas personalizadas |
| **Facturación** | Agente de procesamiento | Conciliación de facturas |
| **RRHH** | Agente de onboarding | Incorporación de empleados |
| **Compliance** | Agente de auditoría | Verificación de regulatory |
| **PMO** | Agente de tracking | Seguimiento de proyectos |

```
  │          │          │           └─ Coordina agentes
  │          │          └─ Actúa autónomamente

  └─ Responde preguntas
```
